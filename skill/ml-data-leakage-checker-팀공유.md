# ml-data-leakage-checker 팀 공유 문서

## 1. 스킬 핵심

- ML 전처리 코드를 넣으면 데이터 누수 패턴을 자동 검사하는 점검기
- 확정위반/의심/이상없음 3분류로 결과를 짧게 출력
- 줄 번호와 수정 방향만 제공하는 최소 출력형 스킬
- 과정 설명은 생략하고 결과만 간결하게 제시
- 원본 코드는 수정하지 않고 지적만 제공

## 2. 해결하고 싶은 문제

- 전처리 코드 검토 때마다 데이터 누수를 사람이 직접 찾는 반복 작업
- 타겟 인코딩, 피처 추가, 스케일링, CV 분할, 시계열 순서 변경 시 재확인이 길어지는 문제
- 실행은 되고 점수도 좋지만 누수가 숨어 늦게 발견되면 튜닝·모델 비교를 처음부터 다시 해야 하는 문제
- 코드가 길어질수록 누수 지점을 한 번에 파악하기 어려운 문제

## 3. 주요 사용자

- ML 전처리/학습 파이프라인을 작성·수정하는 개발자
- 모델 학습 전 코드 검토를 자주 수행하는 분석·ML 엔지니어
- 팀 내에서 전처리 코드 리뷰를 빠르게 공유·점검하려는 구성원
- "맞는 것만 pass"처럼 과잉 판정 없이 체크리스트형 결과가 필요한 사용자

## 4. MVP에 들어갈 기능

- 코드 입력만으로 ML 전처리 코드 여부 판정
- split 경계와 fit 호출 위치 수집 및 순서 비교
- 전체 데이터 기준 fit, 타겟 직접 사용, 시계열 셔플 등 주요 누수 패턴 탐지
- 사용자 정의 함수 안 fit과 객체 전달/재할당 추적
- 파이프라인 정상 사용 시 오탐 완화
- 노트북 셀 순서 한계 안내
- 분할 경계가 없으면 판정 불가 표시
- 확정위반엔 이유 한 줄 포함, 결과는 3분류+줄 번호+수정 방향만 출력
- 빈 입력, 비파이썬, ML 코드 아님, split 없음 등 예외 사유 안내
- 다중 파일, 표준입력, 코드 문자열 입력 지원
